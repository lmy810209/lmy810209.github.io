Requirements

macOS 13 Ventura or later. Apple silicon and Intel are both supported.

Questions people ask

Are my images uploaded anywhere?

No — and not by choice alone. Pinch ships without the network entitlement, so macOS itself will not let the app open a network connection. There is no account, no analytics, and no crash reporting. See the privacy policy.

My PNG barely got smaller. Why?

PNG is a lossless format, so the quality slider does not apply to it. Two things help:

  • Lower PNG Colors. Screenshots, diagrams and charts usually look identical at 256 colors and shrink by 70–85%.
  • Or switch Output Format to WebP or HEIC, which compress photographic images far better than PNG can.

What is WebP, and should I use it?

WebP is an image format made for the web. At the same visible quality it is typically 25–50% smaller than JPEG, and every current browser supports it. If the file is going on a website, choose WebP. If you are sending it to a person, or putting it into a document or an older app, keep JPEG — it opens everywhere.

Where do the compressed files go?

Into the folder you pick under Save Location. Pinch remembers that folder between launches. After a batch finishes, Show in Finder opens it. You can also turn on Replace Originals to overwrite the files in place — available only when you are not changing the format.

The file did not reach my target size.

Pinch will not degrade an image past the point where quality collapses, so a target it cannot honestly hit is reported instead of faked. PNGs with many colors are the usual case. Turning on Limit Longest Side is the reliable fix — halving the dimensions cuts far more weight than any amount of extra quality loss.

Does compressing remove my camera info or GPS location?

Only if you ask. Keep All is the default and preserves everything. Remove Location Only strips GPS coordinates but keeps camera settings and the capture date. Remove All clears the metadata entirely.

What if a file would get bigger?

Pinch compares the result against the original before writing anything. If compressing would not help, the original is kept and the file is left untouched.

Can I compress a whole folder at once?

Yes — drop the folder onto the window and every image inside is queued. You can also paste a screenshot straight from the clipboard with ⌘V.
